# Rep-Documentacao
APP-BLOG

- Sistema de blog com área publica e painel adminitrativo

TECNOLOGIAS
  
- PHP 8
- MySQL
- HTML e CSS
  
FUNCIONABILIDADES
 
 - Front-end: listar e ler postagens
 - Painel Admin: login, criar, editar e excluir postagens

COMO EXECUTAR

1. Instale o XAMPP e inicie o Apache e o MySOL
2. Copie a pasta app-blog para htdocs
3. Importe o arquivo banco/app.blog.slq no PhpMyAdmin
4. Acesse http://localhost/app.blog

ESTRUTURA DE PASTAS

- /admin:painel administrativo
- /public: páginas de frot-end
- /css: estilos
- /includes: conexão com o banco e funçoes
- /banco: script SQL
- /docs: documentação
